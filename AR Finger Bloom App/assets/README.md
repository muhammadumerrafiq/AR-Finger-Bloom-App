# assets/

This directory can hold optional custom image assets:
- `flower.png` (Custom center flower sprite)
- `petals.png` (Custom particle sprites)

Currently, the application procedurally generates high-quality Vector graphics and utilizes system Emojis for optimal responsiveness, styling, and load times. If you wish to use PNG sprites, you can import them here and load them in `script.js` using `new Image()`.
